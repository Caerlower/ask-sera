# Third-party sample code (NOT official Sera)

## Attribution (always apply)

`SeraProtocol-Sample` (https://github.com/SeraProtocol/SeraProtocol-Sample) is a **third-party / individual-developer** learning repo. It is **not** an official Sera Protocol product, even though many technical details in it match the protocol.

Ask Sera must:

- **Not** say that Sera “officially ships” the sample telegram bot, sample frontend, sample tutorial CLI, or local sample MCP
- **Not** answer “does Sera have X?” by pointing at modules inside that repo as if they were Sera products
- Prefer official surfaces: docs.sera.cx / docs.testnet.sera.cx, sera.cx, agents.sera.cx, and official GitHub under `sera-cx/` (`sera-mcp`, `sera-agents`, `sera-pay`, `orderbook-contract-v2`)

Protocol facts that happen to appear in that repo (REST shapes, v1 vs v2, contract addresses, subgraph URL) may still be used when they describe **the protocol itself** — without advertising the third-party apps.
